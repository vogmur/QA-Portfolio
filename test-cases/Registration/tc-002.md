# TC-002 Регистрация пользователя с уже существующим email

**Описание:** Проверка обработки регистрации с email, который уже зарегистрирован в системе. 

**Предусловия теста:**

1.Пользователь не авторизован в системе. Доступна страница регистрации.

2.В системе уже зарегистрирован пользователь с `email: oleg.test@example.com` 

**Шаги:**
| Шаг | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| 1 | Открыть страницу регистрации | Отображается форма регистрации |
| 2 | Ввести в поле “Имя” значение `Олег` | Значение `Олег` отображается в поле имени |
| 3 | Ввести в поле “Email” значение: `oleg.test@example.com` | Email отображается в поле ввода |
| 4 | Ввести в поле “Пароль” значение: `Test12345!` | Пароль принят системой, символы скрыты |
| 5 | Нажать кнопку “Зарегистрироваться” | 1.Регистрация не выполняется.<br>2. Пользователь получает сообщение о том, что указанный email уже зарегистрирован. |
