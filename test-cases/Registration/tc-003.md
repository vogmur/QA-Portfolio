# TC-003 Проверка обязательного поля "Имя" при регистрации

**Описание:** Проверка невозможности регистрации пользователя без заполнения обязательного поля "Имя".

**Предусловия:**

1. Пользователь не авторизован в системе. Доступна страница регистрации.
   
 **Шаги:**

 | Шаг | Действие | Ожидаемый результат |
 | :--- | :--- | :--- |
 | 1 | Открыть страницу регистрации.| Отображается форма регистрации с полями: “Имя”, “Email”, “Пароль”, и кнопкой “Зарегистрироваться”. | 
 | 2 | Оставить поле “Имя” пустым. | Поле “Имя” не содержит значения. |
 | 3 | Ввести в поле “Email” значение: oleg.test@example.com | В поле “Email” отображается значение: oleg.test@example.com |
 | 4 | Ввести в поле “Пароль” значение: Test12345! | В поле “Пароль” отображается введённое значение в скрытом виде. |
 | 5 | Нажать кнопку “Зарегистрироваться”. | Регистрация не выполняется. Отображается сообщение о необходимости заполнить поле “Имя”. |
