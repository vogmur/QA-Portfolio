# TC-004 Авторизация зарегистрированного пользователя

**Описание:** Проверка возможности авторизации зарегистрированного пользователя с использованием действующих учётных данных.

**Предусловия:**
1. Пользователь зарегистрирован в системе. В системе существует учетная запись с email `oleg.test@example.com` и паролем `Test12345!`.

**Шаги:**
| Шаг | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| 1 | Открыть страницу авторизации |Отображается форма с полями “Email”, “Пароль” и кнопкой “Войти” |
| 2 | Ввести в поле “Email” значение `oleg.test@example.com` | В поле “Email” отображается значение `oleg.test@example.com` |
| 3 | Ввести в поле “Пароль” значение: `Test12345!` | В поле “Пароль” отображается введённое значение в скрытом виде (точками) |
| 4 | Нажать кнопку “Войти” | Пользователь успешно авторизован. Открывается личный кабинет пользователя |
