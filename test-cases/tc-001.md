# TC-001  Регистрация нового пользователя

**Описание**: Проверка возможности создания нового аккаунта пользователем с уникальным email.

**Предусловия теста:**

1. Пользователь не авторизован в системе. Доступна страница регистрации.

2. Email `oleg.test@example.com` отсутствует в базе данных.

**Шаги:**

| Шаг | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| 1 | Открыть страницу регистрации | Отображается форма регистрации с полями:  Имя, Email, Пароль, кнопка "Зарегистрироваться" |
| 2 | Ввести в поле “Имя” значение `Олег` | Значение `Олег` отображается в поле ввода |
| 3 | Ввести в поле “Email” значение `oleg.test@example.com` | Email отображается в поле ввода |
| 4 | Ввести в поле “Пароль” значение `Test12345!` | Пароль принят системой, символы скрыты (точками) |
| 5 | Нажать кнопку “Зарегистрироваться” | 1. Создан новый пользователь.<br>2.Отображается сообщение об успешной регистрации.<br>3. Пользователь получает доступ к аккаунту. |
