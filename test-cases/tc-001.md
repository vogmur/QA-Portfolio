# TC-001  Регистрация нового пользователя

**Описание**: Проверка возможности создания нового аккаунта пользователем с уникальным email.

**Предусловия теста**:

1. Пользователь не авторизован в системе - Пользователь не имеет активной сессии. Доступна страница регистрации.

2. Email oleg.test@example.com отсутствует в базе данных - Пользователь с указанным email не найден. Email доступен для регистрации.

**Шаги**:

1.Открыть страницу регистрации - Отображается форма регистрации с полями:Отображается форма регистрации с полями:

   - Имя

   - Email

   - Пароль

   - Кнопка зарегистрироваться

2.Ввести в поле “Имя” значение: “Олег” - Значение ”Олег” отображается в поле имени.

3.Ввести в поле “Email” значение: oleg.test@example.com - Email отображается в поле ввода.

4.Ввести в поле “Пароль” значение: Test12345! - Пароль принят системой, символы скрыты.

5.Нажать кнопку “Зарегистрироваться”:
  
   - Создан новый пользователь.

   - Отображается сообщение об успешной регистрации.

   - Пользователь получает доступ к аккаунту.
